# Production Character Body Pack Prompt Template

Use this note in future 250-frame Character Body generation instructions:

> **IMPORTANT — CHARACTER BODY PACK ONLY**
>
> This Character Body Pack contains ONLY the fighter body animation.
>
> Do NOT draw full projectile travel, full-screen Ultimate background, large detached hazards, persistent traps, screen-wide beams, summoned companions, or the complete transformed-mode moveset inside the Character Body cells. Those belong to separate Production Asset Packs.
>
> Special frames may show only the fighter's charge, release gesture, muzzle/mouth flash, recoil, and recovery.
>
> Ultimate frames may show only activation, casting, transformation handoff, and recovery.
>
> Detached Projectile / Effect / Hazard art uses its own arbitrary-aspect-ratio pack. Full-screen Ultimate art uses a separate 16:9 `ULTIMATE_SCREEN` pack. A full alternate body such as `SUPER_DOGE` or `TRUE_FACE` uses a separate `MODE_FIGHTER` pack.
