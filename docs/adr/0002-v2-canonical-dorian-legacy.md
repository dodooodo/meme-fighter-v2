# ADR 0002: v2 is canonical; Dorian is legacy reference

## Status
Accepted

## Context
Two repositories contain relevant implementation history but different stacks.

## Decision
Only `meme-fighter-v2` is production authority. `Dorian` is read-only evidence.

## Consequences
Legacy solutions require adaptation and a v2 task/spec; no architecture is
imported merely because it already exists in Dorian.
