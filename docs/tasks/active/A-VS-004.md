# Task

## Goal

Make Golden Pair combat feedback use clear, consistent presentation-only tiers
for hit, block, throw, KO, special, and ultimate events.

## Context

`A-VS-003` makes every Golden Pair animation reachable. The automatable part
of this pass is a coherent feedback hierarchy: light < heavy < special <
ultimate, distinct block feedback, a KO peak, and brief screen white flashes.

## Existing Behavior To Preserve

`BattleSimulation` remains the only gameplay authority. Existing MoveData
hitstop, timing, damage, collision, snapshot, replay, and hash behavior must
not change.

## Required Change

Centralize presentation feedback profiles; add a white-flash layer; make VFX,
camera impulse, and named audio-cue tiers agree; add focused regression tests.

## Public/API Contract

Presentation feedback accepts `CombatEvent` observations only and performs no
gameplay mutation.

## Implementation Constraints

Do not modify gameplay hitstop. Do not use RNG or simulation time for visual
feedback. Missing authored audio/Ultimate assets remain explicit gaps.

## Edge Cases

Duplicate events emit only once through the existing ledger. Round reset clears
transient visuals. Charged special move IDs share the special tier. Human play
and visual/feel approval is required before this task may be marked `done`.

## Acceptance Criteria

- Higher-impact moves produce monotonically stronger VFX/camera/flash feedback.
- Blocks are distinct from hits and KO is prominent.
- Feedback remains a read-only presentation observer.
- Automated checks pass.
- A human records the Golden Pair play/visual/feel checklist result.

## Rollback / Recovery Notes

Revert the feedback profile, flash, presenter wiring, and tests together; no
gameplay-state migration or data rollback is required.

## Out of Scope

Gameplay hitstop retuning, combat data changes, source-art repair, and claiming
authored SFX/Ultimate art that does not exist.
